## 겹치는 선행연구: Goodarzi, Schütze, Schneider, JSSS 14:119 (2025)
DOI: 10.5194/jsss-14-119-2025

- **설정**
  - 같은 ZeMA 유압 데이터, **PS1만** 사용
  - 대상: 축압기, 밸브
  - **LOGO 그룹 = 냉각기 3 / 20 / 100%**. 우리 "냉각기 하나 빼기"와 같은 평가입니다.
- **방법**: AutoML
  - FESC: 특징 추출 7종 × 특징 선택 5종 × 분류기 2종 = 70개 조합
  - DNN: MLP, ConvNet, ResNet, WaveNet
- **결과**
  - LOGO 최고 정확도: 축압기 **85%**, 밸브 97%
  - 최고와 최저 모델의 차이가 약 60%입니다. 최고값은 LOGO 결과를 보고 고른 모델이라 낙관적일 수 있습니다.
- **다루지 않은 것**
  - 물리 기반 특징·모델
  - 도메인 적응과 전이학습. 논문이 범위 밖이라고 명시했습니다.
  - 측정 순서 블록 누설
- **우리에게 주는 영향**
  - "냉각기(온도) 하나 빼기 평가"는 노벨티가 **아닙니다**. 인용해야 합니다.
  - 정확도는 **우리(0.78–0.81)가 그들 최고값(0.85)보다 낮습니다.** 정확도 우위를 주장할 수 없습니다.
- **여전히 남는 우리 고유 기여**
  - 물리 추정값 1개 + 파라미터 2개로 약 0.78–0.82 → 70개 이상의 파이프라인 중 사후 선택한 최고 모델에 근접
  - 데이터 효율: 라벨 8사이클로 0.77. 그들이 범위 밖으로 둔 적응·전이 문제를 다룹니다.
  - 연속 충전압(bar) 추정, 물리 해석이 가능한 상태량
  - Enejor식 block-CV의 측정 순서 누설 발견(사이클 번호만으로 0.874)
