## 5. 센서값 하나 + 임계값 규칙 vs ML (`rule.py`)
규칙: 학습 데이터에서 가장 잘 맞는 특징 1개를 고르고 임계값을 학습합니다(클래스 수만큼 구간). 정확도입니다.

| 대상 | block-CV 규칙 | block-CV ML | 새 온도 규칙 (c3/c20/c100) | 새 온도 ML |
|---|---|---|---|---|
| 냉각기 | 0.943 (CE) | 0.996 | 해당 없음 | 해당 없음 |
| 펌프 | 0.978 (SE) | 0.998 | 0.754 / 0.971 / **0.344** (평균 0.690) | 0.77 / 1.00 / 1.00 (평균 0.923) |
| 밸브 | **1.000** (PS2 구간3 분산) | 1.000 | **0.743** / 1.0 / 1.0 (평균 0.914) | 0.999 / 1.0 / 1.0 |
| 축압기 | 0.679 | 0.976 (누설 포함) | 평균 0.423 | 평균 0.596 |

- 조건이 고정되면 밸브와 펌프는 신호 하나로도 됩니다.
- 온도가 바뀌면 단일 임계값이 무너지고, 다변수 ML이 버팁니다.
