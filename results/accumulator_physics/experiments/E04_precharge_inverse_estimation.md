## 7. 충전 램프로 충전압 직접 역추정 (`p0_inverse.py`, `p0_cv.py`, 규격은 RIG_SPECS_KO.md)
- **조건**: 사이클 시작 후 약 1초 동안 V10이 닫혀 있습니다(FS1 = 0). 펌프 7.5 L/min이 전부 축압기(V0 = 0.6 L)로 들어가고, 이때 PS1이 약 151 → 190 bar로 오릅니다.
- **식**: 단열 n = 1.4에서 X(t) = p_s^(−1/n) − p(t)^(−1/n)는 시간에 선형입니다. 기울기를 s라 하면 p0 = (Q / (V0·s))^n 입니다.
- **사이클별 적합도**: R² 중앙값 0.9999. 물리식 형태가 실제 측정과 거의 완벽하게 맞습니다.
- **추정 p0 중앙값** (n = 1.4, Q 공칭값, 실제 90/100/115/130 순서)
  - c20: 113 / 131 / 146 / 158
  - c100: 106 / 125 / 139 / 149
  - 순서가 단조롭고 비율도 실제(1.44)에 가깝습니다(1.35–1.40). 다만 약 +15–25 bar의 계통 오프셋이 있습니다.
- **FS1 기반 유효 Q는 사용하지 않았습니다.** 고온 c3 구간에서 FS1이 비정상(3.9 L/min)이라 추정이 실패하기 때문입니다.

새 온도 시험(냉각기 하나 빼기) 정확도입니다.

| 방법 | c3 (고온) | c20 | c100 (저온) | 평균 |
|---|---|---|---|---|
| p0_hat(T) + 선형 보정 | 0.471 | 0.750 | 0.688 | 0.637 |
| **p0_hat + 기체 온도 보정(샤를 법칙, 20°C 환산) + 선형 보정 (파라미터 2개)** | 0.586 | 0.847 | **0.908** | **0.780** |
| RF에 p0_hat 하나만 | 0.508 | 0.598 | 0.596 | 0.568 |
| RF: K 6개 (이전) | 0.614 | 0.837 | 0.820 | 0.757 |
| RF: p0_hat + K + T | 0.651 | 0.890 | 0.846 | 0.796 |
| **RF: p0_hat + 응답시간 + K + T** | **0.748** | 0.887 | 0.791 | **0.809** |

- **물리 추정값 1개 + 선형 보정 2파라미터(0.780)가 구간 특징 1,184개 RF(0.611)를 이깁니다.**
- 같은 p0_hat을 RF에 넣으면 0.568로 떨어집니다. 트리 모델은 범위 밖으로 외삽하지 못하고, 물리식 기반 선형 보정은 외삽하기 때문입니다.
- 기체 온도 보정(물리)을 넣으면 0.637 → 0.780으로 오릅니다.
- 연속값 오차(MAE)는 c100 3.4 bar, c20 4.0 bar, c3 5.8 bar입니다.
- 고온 c3는 여전히 약합니다. FS1과 PS1 정상상태 이상과 같은 측정 세션 문제일 가능성이 있습니다.
