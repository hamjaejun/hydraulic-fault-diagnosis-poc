## 12. L4 온도 빼기(4개 부품) + 두 상태 보정 (`next_l4_twostate.py`, `twostate_adapter.py`)
### A. L4 냉각기 하나 빼기 (처음 보는 오일 온도), 정확도 c3 / c20 / c100 → 평균
| 부품 | 사이클 번호만 | 전체 통계(187) | 구간(1184) | 물리 |
|---|---|---|---|---|
| 밸브 | 0.51 | 0.64 / 0.98 / 0.88 → 0.83 | 1.00 / 1.00 / 1.00 → **1.00** | – |
| 펌프 | 0.55 | 0.77 / 1.00 / 0.97 → 0.91 | 0.75 / 1.00 / 1.00 → 0.92 | – |
| 축압기 | 0.37 | 0.19 / 0.18 / 0.26 → 0.21 | 0.50 / 0.72 / 0.64 → 0.62 | 0.75 / 0.88 / 0.78 → **0.81** |
- 밸브는 구간 특징이면 온도가 바뀌어도 해결됩니다. 펌프는 가장 차가운 조건(c3)에서만 0.75–0.77로 떨어집니다.
- 축압기는 물리 특징이 있어야 버팁니다. 사이클 번호로는 누설이 생기지 않는 분할입니다.

### B. 두 상태 보정: 새 온도에서 축압기 130 bar와 90 bar 사이클만 k개씩 측정 → 100/115 bar도 맞히나?
- 'mid'는 새 온도에서 한 번도 본 적 없는 100/115 bar 사이클의 정확도입니다.

| 방법 | k=1 전체/mid | k=2 | k=5 | k=10 |
|---|---|---|---|---|
| 물리, 원 조건 보정만 (k=0 기준선) | 0.780 / 0.747 | | | |
| 물리, 새 조건 2점 직선만 | 0.731 / 0.522 | 0.740 / 0.518 | 0.760 / 0.530 | 0.771 / 0.530 |
| ML(구간 특징), 원 조건 + 앵커 | 0.671 / 0.138 | 0.662 / 0.109 | 0.658 / 0.097 | 0.634 / 0.029 |
| ML(물리 특징), 원 조건 + 앵커 | 0.816 / 0.680 | 0.805 / 0.597 | 0.800 / 0.510 | 0.787 / 0.457 |
| **어댑터: 원 조건 곡선 + 2파라미터(배율·오프셋)** | 0.798 / 0.755 | 0.816 / 0.776 | **0.858 / 0.804** | 0.855 / 0.822 |

- 어댑터 k=5 온도별 정확도: c3 0.784, c20 0.886, c100 0.903 (50회 반복 평균).
- **2점 직선만으로는 안 되는 이유**: 충전압 추정값이 높은 쪽에서 포화됩니다. c3의 클래스 중앙값은 90→107.8, 100→122.9, 115→134.9, 130→138.2 bar입니다. 그래서 곡선 모양은 원 조건 데이터(베이스 모델)에서 가져오고, 새 조건에서는 배율과 오프셋 두 개만 맞추는 구조가 필요합니다.
- **ML에 앵커를 섞으면 오히려 나빠집니다**(mid 0.03–0.14). 새 조건에서 본 클래스(90/130)로 쏠리기 때문입니다.
- 비교: Goodarzi 2025 최고 0.85는 새 온도의 라벨을 쓰지 않았습니다. 우리 0.858은 양 끝 상태 10사이클을 쓴 값이라 조건이 다릅니다. 같은 조건(라벨 0)에서 우리 값은 0.78–0.81입니다.
