# Accumulator physics-guided state estimation (research/accumulator-physics)

> 축압기 충전압을 물리식으로 역산하는 모듈과, 처음 보는 운전 조건·복합 고장에서의 일반화를 검증한 연구입니다.
> 기존 baseline 파일은 수정하지 않았고, 새 파일만 추가했습니다.
> - 스크립트: `accumulator_physics/`
> - 결과: `results/accumulator_physics/`

## 한 줄 요약
- 일반 ML은 무작위 분할에서 99%가 나옵니다. 하지만 처음 보는 오일 온도나 복합 고장에서는 축압기 진단이 0.2 수준까지 떨어집니다.
- 충전 램프 구간(처음 약 1초)에 기체법칙을 적용해 충전압(bar)을 역산하는 물리 모듈을 붙이면 0.78–0.81을 유지합니다.
- 새 조건에서 양 끝 상태(90/130 bar)를 10사이클 측정하고 2파라미터 어댑터로 보정하면 0.86이 됩니다.

## 실행 방법
1. 원시 데이터를 받습니다. 기존 `download_data.py`를 쓰면 `data/raw/*.txt`가 생깁니다.
2. 아래 명령을 차례로 실행합니다.
   ```powershell
   cd accumulator_physics
   mkdir work; cd work
   python ../load.py ../../data/raw hyd.npz   # 원신호 → hyd.npz
   python ../feat.py                           # 특징 → feats.npz (W: 전체 통계 187, I: 구간·과도응답 1184)
   python ../phys.py                           # 기체법칙 특징 → phys.npz
   python ../p0_inverse.py                     # 충전압 역산 → p0.npz
   python ../<실험 스크립트>.py                  # 아래 표 참고
   ```
- `work/` 폴더와 npz·zip 파일은 `accumulator_physics/.gitignore`로 커밋에서 제외됩니다.
- 2026-11-23에 원시 데이터부터 다시 만들어 동일한 수치가 나오는 것을 확인했습니다.
- 파이썬 환경: numpy, scipy, scikit-learn (Anaconda 기본 환경).
- 분류기는 주로 RandomForest(200–300 trees, random_state 0)를 썼습니다.

## 핵심 결과 (정확도)
### 검증 사다리
| 단계 | 냉각기 | 밸브: 전체 통계 → 구간 | 펌프 | 축압기: 전체 → 구간 → **물리** |
|---|---|---|---|---|
| L1 무작위 | 1.00 | 0.99 → 1.00 | 1.00 | 0.99 |
| L2 블록 | 0.96 | 0.94 → 1.00 | 1.00 | 0.83 → 0.98 → 0.95 |
| L3a 조합 빼기 | 0.95 | 0.94 → 1.00 | 1.00 | 0.80 → 0.96 → 0.95 |
| L3b 단일 → 복합 고장 | 1.00 | 0.39 → **0.77** | 0.63–0.71 | 0.23 → 0.41 → **0.63** |
| L4 처음 보는 온도 | – | 0.83 → **1.00** | 0.91–0.92 | 0.21 → 0.62 → **0.81** |

- **사이클 번호만 넣어도 축압기가 맞혀집니다.**
  - L2 블록 분할에서 0.875, L3a 조합 빼기에서 0.858입니다.
  - 측정 순서가 중첩 구조(냉각기 > 축압기 > 펌프 > 밸브)라서, 블록이나 조합 단위로 빼도 시간 위치가 상태를 알려 줍니다.
  - L4에서는 0.37로 떨어지므로 누설이 거의 없습니다.
  - baseline의 Block-aware·Condition Holdout 축압기 점수(macro-F1 0.84–0.90)를 해석할 때 이 점을 함께 고려하는 것이 좋겠습니다.
- L3b는 온도 변화와 섞여 있습니다. 단일 고장 학습 데이터가 냉각기 100% 조건(약 36 °C)에서만 측정되었기 때문입니다. 학습 데이터도 587사이클로 적습니다.

### 적은 데이터로 보정
- 학습량 곡선: 물리 + 직선 보정은 8사이클로 0.77입니다. 순수 ML은 1,400사이클로 0.62입니다.
- 두 상태 보정(새 온도에서 90/130 bar 각 5사이클):

  | 방법 | 전체 | 100/115 bar |
  |---|---|---|
  | 보정 없음 | 0.78 | 0.75 |
  | 두 점 직선 | 0.76 | 0.53 |
  | ML에 앵커 섞기 | 0.66 | 0.10 |
  | **원 곡선 + 배율·오프셋 어댑터** | **0.86** | **0.80** |

- 다른 장비(PHM 2022 드릴, 장비 하나 빼기):

  | 설정 | 정확도 |
  |---|---|
  | 보정 없음 | 0.70 |
  | 정상 기준 빼기 | 0.85 |
  | 정상 기준 + 클래스당 라벨 2개 | 0.89 |

## 증명된 것과 가설
- **증명됨 (같은 설비 안에서):**
  - 블록·조합 분할에는 측정 순서 누설이 있다.
  - 처음 보는 온도와 복합 고장에서 ML의 축압기 진단이 무너진다.
  - 물리 모듈이 있으면 버틴다.
  - 소량 보정으로 충분하다.
- **가설:** 규격이 다른 회로(축압기 용량, 펌프 유량)로 옮길 수 있다. 다른 규격 회로의 데이터나 시뮬레이션이 필요합니다.
- **새롭지 않음:**
  - 냉각기 빼기 평가: Goodarzi et al. 2025, JSSS 14:119와 같은 방식입니다.
  - 충전압 물리 추정 자체
- **정확도 비교:** 라벨 없이 같은 조건에서는 Goodarzi 2025가 0.85, 우리가 0.78–0.81입니다. 우리 0.86은 새 조건의 10사이클을 쓴 값입니다.
