# 유압 고장진단 프로젝트 정리 (2026-11-21)

## 1. 한 줄 요약
**부품 규격과 물리식으로 만든 "물리 상태량"을 입력으로 쓰면, 고장 데이터가 적어도 처음 보는 운전 조건에서 축압기 고장을 판별할 수 있다.** 다른 규격 회로로의 확장은 본 연구에서 검증할 가설이다.

## 2. 데이터
- **출처**: UCI "Condition Monitoring of Hydraulic Systems"
  - 원본: ZeMA 시험설비, Helwig 학위논문 2018의 "Const. 2", 2014-08-22 측정
- **설비**: 유압 시험설비 **1대**. 다음 4개 부품의 상태를 일부러 바꿔 가며 측정했다.

  | 부품 | 상태 등급 |
  |---|---|
  | 냉각기 | 3 / 20 / 100%. 오일 온도로 보면 약 56 / 45 / 36°C |
  | 밸브 | 100 / 90 / 80 / 73% |
  | 펌프 누설 | 0 / 1 / 2 |
  | 축압기 충전압 | 130 / 115 / 100 / 90 bar. 같은 모델(Hydac SBO330, 0.6 L)의 서로 다른 축압기 4개를 밸브로 교체 |

- **센서 17개**
  - 압력 PS1–6, 모터 전력 EPS1: 100 Hz
  - 유량 FS1–2: 10 Hz
  - 온도 TS1–4, 진동 VS1, 가상센서 CE·CP·SE: 1 Hz
- **규모와 측정 방식**: 60초 고정 작업 사이클 2,205회, 약 37시간 연속 측정. 측정 순서는 냉각기 > 축압기 > 펌프 > 밸브로 중첩됐다.
- **확보한 규격** (학위논문, `poc/hydraulic_originality/RIG_SPECS_KO.md`)
  - 펌프 7.5 L/min, 오일 HLP 32, 릴리프 190 bar
  - 회로도와 센서 위치: PS1은 축압기 옆, FS1은 부하 뒤 귀환 유량

## 3. 부품별 난이도
| 부품 | 같은 조건 | 처음 보는 온도 | 비고 |
|---|---|---|---|
| 냉각기 | 거의 100% | 해당 없음 (온도 자체가 조건) | 센서값 하나로도 판별 가능 |
| 밸브 | 100% | 100% (구간 특징 사용 시) | 첫 하중 변화 뒤 12초 안에 판정 |
| 펌프 | 약 100% | 0.92 (ML), 0.69 (단일 임계값) | 온도에 따라 누설량이 달라짐 → ML 필요 |
| **축압기** | 0.82–0.97 (누설 포함) | **0.20 (기존 방식)** | **가장 어려움 → 연구 대상** |

## 4. 평가 방법과 누설 문제
- **무작위 분할**: 이웃 사이클이 학습과 시험에 동시에 들어가서 점수가 부풀려진다.
- **블록 분할 (Enejor 2026)**: 축압기는 같은 측정 구간이 학습과 시험에 남는다. **사이클 번호만으로 0.874** → 누설이다. *(우리 발견)*
- **냉각기(온도) 하나 빼기**: 처음 보는 운전 조건 평가. Goodarzi 2025도 같은 평가를 사용했다.

## 5. 우리 방법
```
센서 신호 + 규격(V0 0.6 L, 펌프 7.5 L/min, 기체 지수 1.4)
   → [물리 모듈] 충전 램프(첫 약 1초, 밸브 닫힘) PS1 곡선에 단열 기체식 적합 → 충전압 p0 역산
                 + 기체 온도 보정 (20°C 환산)
   → [입력 특징] p0 추정값 + 기체법칙 특징 K + 응답시간 + 오일 온도
   → [모델] 선형 보정(파라미터 2개) 또는 RF
   → 축압기 등급 / 충전압(bar)
```
- 물리식이 하는 일은 **레이블 추가가 아니라 입력 특징(물리 상태량)을 하나 추가하는 것**이다. 정답 레이블은 여전히 측정 데이터에서 온다.
- 물리식 적합도는 사이클별 R² 0.9999이다.

## 6. 핵심 결과 (처음 보는 온도 기준)
| 방법 | 정확도 |
|---|---|
| 기존 방식 (사이클 전체 통계 187개, ML) | 0.20 |
| 구간 특징 1,184개 (ML) | 0.61 |
| 응답시간 특징 | 0.71 |
| **물리 p0 + 온도 보정 + 선형 보정 (파라미터 2개)** | **0.78** |
| **물리 + ML** | **0.81** |
| 참고: Goodarzi 2025 (PS1만, 70개 이상 파이프라인 중 최고) | 0.85 |

**데이터 효율** (라벨 사이클 수 N)

| 방법 | N = 8 | N = 1,400 |
|---|---|---|
| 물리 + 선형 보정 | **0.77** | 0.78 |
| 순수 ML (구간 특징) | 0.38 | 0.62 |

**실패한 시도** (한계로 명시)
- 점도 보정: 효과 없음
- 정상 데이터만으로 보정: 특징 평행 이동, 물리 파라미터 보정 모두 실패
  - 원인: 충전압 한 점의 정보로는 비선형 오차를 구별할 수 없다.
  - 필요 조건: **충전압 2개 이상의 상태**에서 라벨이 붙은 사이클이 필요하다.
- 고온(56°C) 조건은 여전히 약하다 (0.59–0.75).
- 펌프 누설이 p0 추정을 4–10 bar 부풀린다 → ML 보완이 필요한 근거

## 7. 노벨티 (최종 문장)
> 물리 모듈이 장비 규격을 입력받아 센서 신호를 규격과 무관한 상태량(충전압 등)으로 바꾸고, 진단 모델은 그 위에서 학습한다. 그래서 새 조건에서는 **충전압이 다른 상태 몇 개의 소수 사이클**로 보정할 수 있다. 목표는 정확도 경쟁이 아니라, **같은 수준의 정확도를 훨씬 적은 데이터와 해석 가능한 물리량으로** 얻는 것이다.

- **노벨티가 아닌 것**
  - 온도 하나 빼기 평가 (Goodarzi 2025)
  - 물리 기반 충전압 추정 자체 (Aalborg 석사논문, Liniger 등 선행연구 있음)
  - 정확도 우위
- **우리 고유 기여**
  - 물리 + 소량 보정의 데이터 효율 (Goodarzi가 범위 밖으로 둔 적응 문제)
  - 해석 가능한 연속 충전압 추정
  - block-CV 누설 발견

## 8. 증명된 것 vs 가설
| 주장 | 상태 |
|---|---|
| 처음 보는 **온도**로 이전 | PoC로 증명 (0.78–0.81) |
| **적은 라벨**로 보정 | PoC로 증명 (8사이클로 0.77) |
| 보정에 없던 **중간 충전압·다른 축압기 실물** 예측 (130 + 90으로 보정 → 100·115 예측) | **실험 필요** |
| **다른 규격 회로**로 이전 | **가설**. 공개 데이터가 없어 1D 시뮬레이션이나 자체 실험으로 검증 필요 |
| 정상 데이터만으로 보정 | 실패. 실제 기체·다이어프램을 포함한 1D 디지털 트윈 과제 |
